# Kang Choi — Personal Portfolio

Personal portfolio covering hardware and digital circuit design, research, experience, and awards.

Built with HTML, CSS, and JavaScript. Open index.html locally or visit the published GitHub Pages site.

## Update the portfolio

Edit profile.js to update profile details, research abstracts, authorship, statuses, repository links, experience, and awards. Store photos and figures under assets/.

The CV link can be enabled by placing a PDF in assets/ and setting links.cv to its relative path.
